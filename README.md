# YouTube Homepage UI Clone (HTML & CSS)

A static clone of the YouTube homepage built using **only HTML and CSS** as a learning project to strengthen frontend fundamentals.

This project focuses purely on **UI structure and styling** — no JavaScript, backend, or frameworks involved.

---

## 🚀 Project Overview

The goal of this project was to understand how real-world websites structure their layouts and manage spacing, alignment, and responsiveness using core web technologies.

By recreating the YouTube homepage UI, I practiced translating a complex design into clean, maintainable HTML and CSS.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure and layout
- **CSS3**
  - Flexbox
  - CSS Grid
  - Responsive design principles

---

## ✨ Key Learnings

- Writing clean, semantic HTML for large UI layouts  
- Building responsive sections using Flexbox and Grid  
- Managing spacing, alignment, and layout hierarchy  
- Understanding real-world UI composition  
- Strengthening frontend fundamentals before moving to frameworks like React  

---

## 📌 Features

- Static YouTube homepage layout
- Responsive structure (desktop-focused)
- Sidebar, header, and video grid layout
- Pixel-focused UI recreation

> ⚠️ Note: This is a **UI-only learning project**.  
> There is **no JavaScript functionality**, backend, or interactivity implemented.

---

## 🎯 Purpose

This project was built as part of my learning journey to solidify **core frontend concepts** before diving into advanced tools like **JavaScript frameworks, React, and Tailwind CSS**.
